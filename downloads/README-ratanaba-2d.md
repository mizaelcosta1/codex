# Ratanabá Guardians 2D — APK 0.5.1 de teste

Instale `ratanaba-guardians-2d-v0.5.1-debug.apk` em Android 8.0/API26 ou posterior, com Android System WebView atualizado. O aplicativo é offline, contém todos os assets e não solicita permissão de internet. Pode ser instalado ao lado dos APKs Godot antigos porque usa `br.com.ratanaba.guardians2d`.

Abra o APK no Android e autorize a instalação para o aplicativo usado no download, se solicitado. Esta é uma versão assinada para testes, não uma publicação na Play Store. A assinatura e os arquivos foram verificados, mas não houve instalação nem medição em Android físico nesta entrega.

Os saves ficam no armazenamento privado da WebView. Os saves do navegador não são importados automaticamente. APKs reconstruídos com outra chave de debug podem exigir desinstalação; preserve sua chave de desenvolvimento fora do Git se quiser atualizar o mesmo aplicativo. O workflow gera uma chave temporária, portanto os artifacts de CI podem ter assinatura diferente deste download.
