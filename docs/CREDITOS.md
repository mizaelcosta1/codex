# Créditos

Código, receitas de modelos e sons sintetizados: produzidos nesta tarefa para
o projeto do usuário. Personagens inspirados em figuras do folclore brasileiro.
Nenhum modelo foi baixado de marketplace e nenhum serviço pago de geração 3D
foi utilizado.

Godot Engine 4.6.3: licença MIT, incluída em `assets/licenses/GODOT_LICENSE.txt`.
Blender 4.3.2 foi usado como ferramenta de autoria; o projeto é distribuído com
fontes Blender e GLBs editáveis. Os sons foram sintetizados, sem samples externos.

Skills de desenvolvimento utilizadas: powerhouse90/Blender-Superskill e
arjun988/blender-skills. Os checkouts e licenças MIT permanecem no ambiente de
desenvolvimento. São instruções de trabalho; não estão incluídas no APK.
